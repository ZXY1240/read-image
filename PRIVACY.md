# Privacy Policy

Effective date: 2026-08-04

## What this plugin does

Read Image is an open-source plugin that provides MCP tools for reading images, video, web pages, and Windows screenshots. When you call a tool, the selected media is sent to the vision API provider you configured, such as Doubao, GLM, Qwen, or another OpenAI-compatible endpoint.

## Data collection

This project does not operate a backend and does not collect, sell, or share personal data. The maintainers do not have access to your media or API keys.

## Third-party providers

Media is only sent when you explicitly call a read or capture tool. Review the privacy policy of the provider you configure before sending sensitive material. The plugin does not send media automatically.

## Local storage

The plugin may store temporary converted or compressed media in the system temporary directory. It reads API configuration from environment variables or a local `.env` file. Source files are not uploaded beyond the configured provider call.

## Changes

This policy may be updated as the plugin changes. The latest version is published in this repository.
